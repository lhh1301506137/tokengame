# B11：本地 AI 终态与时序取证

## 范围与来源

用户在 B10 实机窗口收尾后要求“继续”。本批是已确认路线内的本地 L3/L4 修补：让下一次授权验证不再依赖宿主读取接口能否返回工具回执，不改变玩法或宿主能力承诺。

B10 已证明一次原任务无点击自动启动，但工具记录为空，THINKING 后跨手回到 IDLE，不能确认是合法沉默还是丢弃。该窗口的结论保持不变：Codex Gate 5 为 blocked，Claude 为 not_run。DEC-20260830-003 的三次输入预算已用完，禁止追加真实 queue、宿主任务消息或模型调用。

权威 `SeatAiStore.onEvent` 已提供来源消息、评估开始、公开发言、沉默、回收与丢弃事件。本批只订阅这一事实源，不新增游戏结果状态，不用浏览器 IDLE 推断成功。

## 实现约束

1. 增加默认关闭的本地记录器，由 `src/run-beta.cjs` 的进程内权威路径接入。唯一启用项为 `TOKENGAME_AI_RECEIPT_FILE`；不设置时不建文件、不加定时器、不增模型、网络或队列调用。远程内核模式无法观察进程内事件，显式启用时应在监听前清楚拒绝，不能产生伪空记录。
2. 输出只包含白名单事件类型、权威序号与时间、运行内关联标识、手数/街道及已知决定/原因。禁止原样保存 payload、聊天、回答、手牌、模型上下文、玩家昵称、凭据、连接文件或任意错误正文。关联标识宜使用运行内不可逆引用，避免通过自由格式 ID 泄漏内容。
3. 文件必须独占新建，不能覆盖旧证据。单次记录须有有限条数、字节数与待写队列；异步磁盘写入不阻塞权威推进。满额、写入失败或异常终止必须可辨识为不完整，不能把截断当成功。
4. 首尾记录标明捕获范围与完整性。关闭时退订、排空并关闭本批文件句柄；启动失败清理本批资源。失败不改变扑克时钟、评估租约、配额或玩家行动。
5. 提供离线汇总工具，关联来源→评估开始→终态；分别报告公开发言、沉默、丢弃、回收后迟到、未结束或 unknown。缺来源/缺开始/缺尾记录、重复冲突、非法时间与畸形输入不能生成虚假的成功与时延。
6. 权威事件时差仅代表本地可见阶段，不等于纯模型推理时间；不会证明模型身份、推理强度、宿主点击状态或失败的 MCP 请求次数。汇总器不自动判定 Gate 5 通过。
7. 不改变浏览器/MCP 公共接口、不翻转 `proactive_wake_verified`，不恢复配置、开放远程监听、增加依赖、暂存或提交。不动旧 beta PID 16608，不修改 B9/B10 冻结证据。

已核对的局部盲区：`HAND_SETTLED`/`engine-*` 等来源未必有同 ID 的 SeatAiStore 事件，不能用排队或开始时间代替来源时间；`resolveTurn` 校验异常或 OFF 摘下回合可能没有终态事件。前者保持来源时差 unknown，后者只称“未观察到终态”，不推断仍在运行。本批不为补齐这些缺口新增权威事件；已观察终态与完整因果链分别报告。

开发中直接反例补充：`primary-close-failure-red.json` 已证实初版将文件关闭失败混入 `capture_complete`，导致内存 false、磁盘 true。Primary 选择拆分事实而非新增临时文件发布协议：捕获内容完整性、写入是否获得成功回执、文件关闭是否获得成功回执分别报告。最后一次写入报错但可能已经落盘时，进程侧捕获完整性为 unknown，不能从报错推导“字节必定没有写入”；离线只能检验实际读到的内容，对写入回执和资源关闭始终为 unknown。beta 在启用记录时输出去敏收尾回执；写入/关闭失败必须非零退出并明确告警。R5 的运行验收同时读取文件与收尾回执，不能只用离线 CLI 的 0 判为运行成功。此澄清不改变游戏规则或真实宿主门禁。

## 冻结验收矩阵

| 编号 | 必须实际到达的边界 | 成功条件 |
| --- | --- | --- |
| R1 | 默认关闭、远程配置、文件冲突/不可写、启动失败 | 无默认副作用；显式配置错误清楚失败；旧文件不变；本批句柄关闭 |
| R2 | 真实权威公开消息→评估开始→公开/沉默 | 汇总分类与事件吻合；可确定的时差准确；不从 IDLE 推断 |
| R3 | 跨手丢弃、OFF/取消、租约回收与迟到解决 | 保留真实终态与原因；回收不等于沉默；不重复计为发言 |
| R4 | 聊天、AI 输出、手牌、令牌及自由 ID 注入 | 落盘及 stdout/stderr 均无敏感哨兵；关联仍可用 |
| R5 | 条数/字节/待写队列满额、延迟写、写失败、关闭失败、重复关闭 | 内存/文件有界；文件与运行收尾分项验证，错误不能被 reader 的 0 掩盖；权威继续，退订及关闭幂等 |
| R6 | 畸形/截断/缺首尾/冲突/缺来源/时间倒退 | unknown、partial 或明确错误，不输出伪成功/伪时延 |
| R7 | 实际 beta 入口与 HTTP 模型命令链路 | 日志来自真实运行入口而非仅测试替身；脚本 AI 与真实模型证据分开 |
| R8 | 定向变异与相邻回归、浏览器 | 针对去敏/完整性/接入的故障确实触发失败；界面正常；不改既有边界 |

测试优先使用可控时钟与显式脚本终态，不靠睡眠等一手结束。需验证实际 beta 的接入；如为了可清理测试抽取可调用启动函数，CLI 仍必须走同一实现，不新增运行时调试命令。最终运行受影响全量 Node 测试一次；定向变异串行并核对源文件恢复，保留所有失败记录。
