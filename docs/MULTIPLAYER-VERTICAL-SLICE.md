# TokenGame 四人牌桌垂直切片

日期：2026-08-26（Asia/Shanghai）

## 当前可运行能力

该切片提供一张本地固定测试桌，包含 A、B、C、D 四个独立玩家身份。服务端负责发牌、盲注、行动次序、合法动作、下注范围、超时、主池/边池、牌型比较和支付；Web 页只展示玩家有权看到的状态并提交动作。

规则基线采用成熟无限注德州扑克，而不是 TokenGame 自创玩法。已实现四轮下注、fold/check/call/bet/raise/all-in、最小完整加注、短额 all-in 不重开、多层边池、平池奇数筹码、弃牌直接获胜、标准摊牌和自愿亮牌。差异化只在 Codex 公开 AI 通道与隐私边界：四个座位旁分别显示 AI 同伴，每席最近一组已公开的人机对话以聊天气泡呈现，完整历史仍在公开事件流。

## 启动、加入与停止

环境要求为 Node.js 22 或更高版本，无第三方运行依赖。

```powershell
npm test
npm run table
```

启动后终端会输出：

- 一个不含底牌的观察者地址；
- A、B、C、D 各自带临时 `player` 与 `token` 查询参数的地址；
- 本地 Codex 桥地址。

要验证真实隔离，应把四个玩家地址分别放进四个独立浏览器上下文。令牌仅用于本地测试，每次重启都会重新生成；它们出现在 URL 中，不满足生产凭据要求。按 `Ctrl+C` 正常停止两个回环服务。进程停止后内存中的牌局、事件和令牌全部丢失。

A 可以在一手结束后点击“新开一手”重置固定测试桌。服务端会轮换庄位并产生新牌和新牌局 ID。当前没有数据库恢复；服务异常退出后只能重新启动一张新桌。

## 权威与隐私合同

- 牌堆、烧牌和未授权底牌只存在于服务端领域对象，不进入公共状态。
- 玩家快照只包含本人的隐藏底牌；观察者在摊牌前看不到任何底牌。
- 标准摊牌公开所有仍在局玩家底牌；弃牌获胜默认不公开，赢家可在结算后自愿公开自己的牌。
- HTTP 动作必须带玩家令牌、预期牌局版本和幂等键。非当前玩家、非法金额、陈旧版本和幂等冲突均被拒绝。
- SSE 首帧与后续刷新按连接身份重新生成投影；客户端可按当前快照恢复，不自行重放和猜测状态。
- 服务端截止时，能够 check 的位置自动 check，否则自动 fold；不会替超时玩家投入筹码。
- 玩家或模型文本只能作为公开语言事件，不能改变服务端认定的手牌、公共牌、合法动作或结算。
- 座位气泡只接受合法 `AI_PROMPT_PUBLISHED` 与匹配的 `AI_ANSWER_PUBLISHED`，并按席位 actor 与 `request_id` 配对；普通 Codex 内容、未知来源、孤立回答和错席回答不会成为牌桌气泡或点亮全局 AI 阶段。

主要本地接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/table/state` | 观察者或携带玩家凭据读取个性化快照 |
| `GET` | `/api/table/events` | 读取不含私有牌的权威公共事件 |
| `GET` | `/api/table/events/stream` | 订阅按身份投影的 SSE 状态 |
| `POST` | `/api/table/actions` | 提交版本化、幂等的玩家动作 |
| `POST` | `/api/table/reveal` | 结算后自愿亮出本人的牌 |
| `POST` | `/api/table/reset` | 由 A 开始下一手固定测试牌局 |

## 浏览器验收

项目的四玩家烟测会创建四个真正隔离的 Chromium context，经 UI 完成三种场景：四轮 checkdown 摊牌、四人 all-in 自动发完公共牌、一次加注后三人弃牌并由赢家自愿亮牌。它同时比较四个视图的公共状态、检查各自底牌隔离，并收集所有页面的控制台错误。

同一烟测还验证四席 AI 始终可见、A 的真实公开请求在四个视图同步经历“生成中→已回答”、B 的通用配对路径、未知/孤立/错席回答隔离、重复请求、旧回答晚到、HTML 文本注入负例、桌面与 560px 窄屏不遮挡，以及公开事件计数与实际完整列表一致。负例和 B 席路径通过测试权威事件注入验证前端投影；这不等同于四个真实 Codex 会话已经绑定。

该脚本依赖 Codex 桌面捆绑的 Playwright 运行时，普通 Node 环境未安装 Playwright 时不应把它当作默认 `npm test`。最新机器结果与截图见 `artifacts/four-player-smoke/`，可复现命令记录在验收证据文档中。

## 明确限制

当前结论只覆盖单进程、单固定桌、合成测试筹码和本机回环访问。尚未实现生产认证、TLS、数据库、断电恢复、远程并发、多桌大厅、内容治理、反串谋、真实价值筹码或合规体系。独立 Web 页面也不等于 Codex Desktop 已支持第三方内嵌牌桌 UI。

Codex 公开 AI 仍沿用已验证的桥接合同，本切片只在牌桌旁展示该通道。当前桥接端点只端到端产生 A / `ai:a` 事件；前端投影已支持 B/C/D 的合法 actor，但没有把四个玩家分别绑定到四个真实 Codex 会话。把本地身份、会话 AI 和远端生产牌桌可靠绑定，属于后续任务。
